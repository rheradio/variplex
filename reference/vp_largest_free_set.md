# The most features that are pairwise free (all three graphs)

The largest set of features that are pairwise free: for every two of
them, the four combinations (both, only one, only the other, neither)
all occur in valid products. The width counts features none of which
requires another; this set also excludes conflicts and at-least-one
lines, so it is the number of truly independent decisions, as far as
pairs go.

## Usage

``` r
vp_largest_free_set(model, exact_limit = 60)
```

## Arguments

- model:

  A model, from
  [`vp_generate()`](https://rheradio.github.io/variplex/reference/vp_generate.md)
  or
  [`vp_read()`](https://rheradio.github.io/variplex/reference/vp_read.md),
  in its complete or its minimal form.

- exact_limit:

  Up to this number of variable features the search is exact; above it,
  a greedy search gives a large free set, and the largest one may be
  larger.

## Value

A tibble with the column `feature`.
