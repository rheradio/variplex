# The independent parts of what is left after some decisions

What is left to decide after some decisions, and how it splits: the
independent parts of the features that the decisions do not settle. A
few decisions taken first, together, can cut a model that is one piece
into parts that teams can then decide apart.

## Usage

``` r
vp_split_after(model, selected = character(0), deselected = character(0))
```

## Arguments

- model:

  A model, from
  [`vp_generate()`](https://rheradio.github.io/variplex/reference/vp_generate.md)
  or
  [`vp_read()`](https://rheradio.github.io/variplex/reference/vp_read.md),
  in its complete or its minimal form.

- selected, deselected:

  The decisions taken first (as in vp_consequences()).

## Value

A tibble with `part`, `size` and `feature` (as vp_independent_parts())
over the undecided features; its attribute "decided" lists the features
the decisions settle.

## Examples

``` r
band <- vp_generate(vp_example("miband3.uvl"), or_graph = TRUE)
vp_split_after(band, selected = "BT40")
#> # A tibble: 1 × 3
#>    part  size feature        
#>   <int> <int> <chr>          
#> 1     1     1 HeartRateSensor
```
