# Features that change state back and forth

Features that flip: they change state (variable, core, dead, absent)
back and forth, at least `min_moves` times. Something in their
conditions is edited again and again; they are worth a closer look.

## Usage

``` r
vp_flip_flops(history, min_moves = 2)
```

## Arguments

- history:

  A history: the versions of a model, from
  [`vp_read_history()`](https://rheradio.github.io/variplex/reference/vp_read_history.md)
  or
  [`vp_history()`](https://rheradio.github.io/variplex/reference/vp_history.md),
  oldest first.

- min_moves:

  The smallest number of changes of state to report.

## Value

A tibble with `feature`, `moves` and `path` (the states in order,
without repetitions).

## Examples

``` r
gens <- c("miband1", "miband2", "miband3", "miband4", "miband6")
history <- vp_history(
  vp_example(paste0(gens, "_realized.uvl")),
  versions = gens,
  or_graph = TRUE
)
vp_flip_flops(history, min_moves = 1)
#> # A tibble: 1 × 3
#>   feature moves path           
#>   <chr>   <int> <chr>          
#> 1 BT40        1 core > variable
```
