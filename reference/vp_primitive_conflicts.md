# The conflicts from which all others follow

The primitive conflicts: the conflicts that are not inherited through a
requirement. Every other conflict follows from one of them. The same as
the file \_\_excludes_primitive.net of Strong4VM.

## Usage

``` r
vp_primitive_conflicts(model)
```

## Arguments

- model:

  A model, from
  [`vp_generate()`](https://rheradio.github.io/variplex/reference/vp_generate.md)
  or
  [`vp_read()`](https://rheradio.github.io/variplex/reference/vp_read.md),
  in its complete or its minimal form.

## Value

A tibble with `from`, `to` and `reach`: how many conflicts of the
excludes graph (atomic sets counted as one feature) this primitive
conflict produces, itself included.

## Examples

``` r
band <- vp_generate(vp_example("miband3.uvl"), or_graph = TRUE)
vp_primitive_conflicts(band)
#> # A tibble: 3 × 3
#>   from           to              reach
#>   <chr>          <chr>           <int>
#> 1 Screen         BT40                6
#> 2 MovementFilter HeartRateSensor     4
#> 3 BLEv40         BLEv42              6
```
