# The size of every version

The size of every version of a history.

## Usage

``` r
vp_history_sizes(history)
```

## Arguments

- history:

  A history: the versions of a model, from
  [`vp_read_history()`](https://rheradio.github.io/variplex/reference/vp_read_history.md)
  or
  [`vp_history()`](https://rheradio.github.io/variplex/reference/vp_history.md),
  oldest first.

## Value

A tibble with `version`, `features`, `core`, `dead`, `requires`,
`excludes`, `atleastone`, `skeleton`, `primitive_conflicts`, `depth`,
`implicit_requires` and `implicit_excludes`.

## Examples

``` r
gens <- c("miband1", "miband2", "miband3", "miband4", "miband6")
history <- vp_history(
  vp_example(paste0(gens, "_realized.uvl")),
  versions = gens,
  or_graph = TRUE
)
vp_history_sizes(history)
```
