# The complete graphs rebuilt from the minimal form

The complete graphs rebuilt from a minimal form (as the command
`strong4vm expand` does): every arrow that follows from a chain, every
conflict inherited downwards, every at-least-one line inherited upwards,
and the atomic sets unfolded. A complete model is returned as it is.

## Usage

``` r
vp_expand(model)
```

## Arguments

- model:

  A model, from
  [`vp_generate()`](https://rheradio.github.io/variplex/reference/vp_generate.md)
  or
  [`vp_read()`](https://rheradio.github.io/variplex/reference/vp_read.md),
  in its complete or its minimal form.

## Value

A model in its complete form.

## Examples

``` r
band <- vp_generate(vp_example("miband3.uvl"), or_graph = TRUE)
mini <- vp_minimal(band)
identical(vp_expand(mini)$requires$from, band$requires$from)
#> [1] TRUE
```
