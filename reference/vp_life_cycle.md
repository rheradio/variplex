# How features move between variable, core, dead, absent

The life cycle of features: how often a feature in one state is in each
state one version later, over the whole history.

## Usage

``` r
vp_life_cycle(history)
```

## Arguments

- history:

  A history: the versions of a model, from
  [`vp_read_history()`](https://rheradio.github.io/variplex/reference/vp_read_history.md)
  or
  [`vp_history()`](https://rheradio.github.io/variplex/reference/vp_history.md),
  oldest first.

## Value

A tibble with `before`, `after`, `n` (moves) and `share` (of the
features that were in state `before`).

## Examples

``` r
gens <- c("miband1", "miband2", "miband3", "miband4", "miband6")
history <- vp_history(
  vp_example(paste0(gens, "_realized.uvl")),
  versions = gens,
  or_graph = TRUE
)
vp_life_cycle(history)
#> # A tibble: 5 × 4
#>   before   after        n  share
#>   <chr>    <chr>    <int>  <dbl>
#> 1 absent   variable    20 0.952 
#> 2 absent   core         1 0.0476
#> 3 core     core        31 0.969 
#> 4 core     variable     1 0.0312
#> 5 variable variable    36 1     
```
