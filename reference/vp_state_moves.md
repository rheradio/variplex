# Features that appeared, disappeared or changed status

Features that appeared, disappeared or changed status between two
versions.

## Usage

``` r
vp_state_moves(old, new)
```

## Arguments

- old:

  The older version of a model (from
  [`vp_generate()`](https://rheradio.github.io/variplex/reference/vp_generate.md)
  or
  [`vp_read()`](https://rheradio.github.io/variplex/reference/vp_read.md)).

- new:

  The newer version of the same model.

## Value

A tibble with `feature`, `before` and `after`, each "variable", "core",
"dead" or "absent".
