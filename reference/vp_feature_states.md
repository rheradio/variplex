# The state of every feature in every version

The state of every feature in every version, in long format (one row per
feature and version).

## Usage

``` r
vp_feature_states(history)
```

## Arguments

- history:

  A history: the versions of a model, from
  [`vp_read_history()`](https://rheradio.github.io/variplex/reference/vp_read_history.md)
  or
  [`vp_history()`](https://rheradio.github.io/variplex/reference/vp_history.md),
  oldest first.

## Value

A tibble with `version`, `feature` and `state` ("variable", "core",
"dead" or "absent").

## Examples

``` r
gens <- c("miband1", "miband2", "miband3", "miband4", "miband6")
history <- vp_history(
  vp_example(paste0(gens, "_realized.uvl")),
  versions = gens,
  or_graph = TRUE
)
vp_feature_states(history)
```
