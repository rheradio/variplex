# Optional features that are not really optional

False-optional features: optional features that are not really optional.
Two definitions are in use: the feature is in every product (Benavides
et al.; it is then core), or it is selected whenever its parent is
(Nieke et al.; the parent then requires it). The graphs decide both
exactly.

## Usage

``` r
vp_false_optional(model, tree)
```

## Arguments

- model:

  A model, from
  [`vp_generate()`](https://rheradio.github.io/variplex/reference/vp_generate.md)
  or
  [`vp_read()`](https://rheradio.github.io/variplex/reference/vp_read.md),
  in its complete or its minimal form.

- tree:

  The feature tree, from vp_read_uvl_tree().

## Value

A tibble with one row per optional feature that is false-optional by
either definition: `feature`, `parent`, `in_every_product` (first
definition) and `whenever_parent` (second; NA when the parent is not in
the graphs, for example because it is abstract).

## Examples

``` r
band <- vp_generate(vp_example("miband3.uvl"), or_graph = TRUE)
tree <- vp_read_uvl_tree(vp_example("miband3.uvl"))
vp_false_optional(band, tree)
#> # A tibble: 0 × 4
#> # ℹ 4 variables: feature <chr>, parent <chr>, in_every_product <lgl>,
#> #   whenever_parent <lgl>
```
