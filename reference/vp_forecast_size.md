# Forecast the size of later versions

Forecast the number of links of later versions from their number of
features. The growth law is fitted on the first `train` versions; a
cruder rule ("links per feature stay as in the last known version") is
given beside it.

## Usage

``` r
vp_forecast_size(history, train)
```

## Arguments

- history:

  A history: the versions of a model, from
  [`vp_read_history()`](https://rheradio.github.io/variplex/reference/vp_read_history.md)
  or
  [`vp_history()`](https://rheradio.github.io/variplex/reference/vp_history.md),
  oldest first.

- train:

  How many of the first versions to fit the growth law on (at least 3,
  and fewer than the versions of the history).

## Value

A tibble with `version`, `links`, `observed`, `growth_law`, `same_ratio`
and the errors of both, as shares.

## Examples

``` r
gens <- c("miband1", "miband2", "miband3", "miband4", "miband6")
history <- vp_history(
  vp_example(paste0(gens, "_realized.uvl")),
  versions = gens,
  or_graph = TRUE
)
vp_forecast_size(history, train = 3)
```
