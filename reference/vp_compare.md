# What changed between two versions

What changed between two versions: one row per graph, as the command
`strong4vm diff` reports it.

## Usage

``` r
vp_compare(old, new)
```

## Arguments

- old:

  The older version of a model (from
  [`vp_generate()`](https://rheradio.github.io/variplex/reference/vp_generate.md)
  or
  [`vp_read()`](https://rheradio.github.io/variplex/reference/vp_read.md)).

- new:

  The newer version of the same model.

## Value

A tibble with `graph`, `kept`, `added`, `removed` (variable features),
`old_links` and `new_links` (among the kept features), `gained`, `lost`,
`jaccard` (links in both / links in either; 1 when nothing changed) and
`spearman` (for requires: how alike the order of the kept features by
in-degree is; NA for the others).

``` r
old <- vp_generate(vp_example("miband3_planned.uvl"), or_graph = TRUE)
new <- vp_generate(vp_example("miband3_realized.uvl"), or_graph = TRUE)
vp_compare(old, new)
```
